# Nykaa Marketing Campaign Performance Dashboard

## 📊 Overview
This project presents an interactive **Power BI dashboard** that analyzes the performance of Nykaa marketing campaigns. The dashboard visualizes key metrics such as **revenue, clicks, impressions, conversions, and ROI** to evaluate campaign effectiveness.

## 🛠 Tools Used
- Power BI Desktop
- CSV Dataset
- DAX (Data Analysis Expressions)

## 📈 Dashboard Features
- KPI Cards: Total Campaigns, Revenue, Clicks, Impressions,Average ROI
- Revenue by Campaign Type chart
- Revenue by Months trend analysis
- Top 5 Campaigns by Revenue table
- ROI by Campaign Type comparison
- Language Performance analysis

## 🎛 Filters
Interactive slicers allow filtering by:
- Year

## 🚀 How to Use
1. Download the repository.
2. Open the `nykaa marketing campaign performance dashboard.pbix` file using **Power BI Desktop**.
3. Use the slicers to explore campaign insights.
